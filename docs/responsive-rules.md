# CARNET-ARCHIVE Responsive Rules

> 기준 프레임은 **PC 1920px**와 **Mobile 393px** 두 개뿐이다. 이 문서는 두 프레임의 차이를 규칙으로 정리한 것이다.
> - **확정**: 두 프레임에서 실측한 규칙
> - **요구사항**: 디자인에는 없지만 요청서에 명시된 규칙 (모바일 상품 목록 2열)
> - **제안**: 디자인에 없는 값. 구현 전에 디자이너 확인이 필요하다. §7에 따로 모았다.

### 1.1 확정된 브레이크포인트
디자인으로 확정할 수 있는 것은 **두 레이아웃(PC / Mobile)이 존재한다**는 사실뿐이다. 어느 폭에서 전환되는지는 디자인에 없다. 전환 지점 제안은 §7.1에 있다.

```
Mobile 레이아웃  ── (전환 지점: 미확정) ──  PC 레이아웃
  기준 393                                  기준 1920
```

## 2. 스케일링 규칙 (확정)

### 2.1 여백과 그리드
| 항목 | PC | Mobile | 규칙 |
|---|---|---|---|
| 페이지 여백 | 60 | 16 | 고정값 전환 |
| 열 gutter | 20 | 8 | 고정값 전환 |
| 콘텐츠 폭 | 1800 | 361 | `100% − 2 × 여백` |

### 2.2 타이포그래피
PC → Mobile 축소율이 요소마다 다르다. 하나의 비율로 일괄 축소하지 말고 **토큰별 고정값을 전환한다.**

| 그룹 | 예 | PC → M | 비율 |
|---|---|---|---|
| 초대형 디스플레이 | 워드마크 / Shop 타이틀 / 섹션 헤딩 | 170→48 / 160→40 / 80→20 | 약 0.25–0.28 |
| 캠페인/컬렉션 헤딩 | 54→10 / 40→14 | | 0.19 / 0.35 |
| 라벨·본문 | 카테고리 24→14, Stockist 28→14, 상품명 16→14 | | 0.5–0.88 |
| 상세 정보 | 16→10, 버튼 20→14, 구매안내 16→8 | | 0.5–0.7 |
| 유지 | 헤더 로고 16, Stockist 도시 10 | | 1.0 |

자간(%)과 행간(auto/130%)은 대부분 PC와 모바일이 같다. 예외: Brand Philosophy 키워드 행간 20px → auto, 상세 상품명 auto → 130%.

### 2.3 이미지 비율 유지 (확정)
- 모든 이미지 컨테이너는 **폭을 레이아웃이 정하고, 높이는 `aspect-ratio`로 계산한다.** 고정 높이를 쓰지 않는다.
- PC와 모바일에서 같은 토큰 비율을 쓴다 ([design-tokens.json](design-tokens.json) `aspectRatio`).

| 이미지 | 비율 토큰 | PC 폭 | M 폭 |
|---|---|---|---|
| 상품 카드 | `product` 3:4 | 587 | 2열 칸 폭 (≈176.5) |
| 카테고리 세로형 | `category-portrait` 3:4 | 587 / 708 | 361 / 176 |
| 카테고리 가로형 | `category-landscape` 465:357 | 465 / 587 | 176–177 |
| 에디토리얼 | `editorial` 3:4 | 587 / 344 / 465 | 269 / 84 |
| Stockist | `stockist-editorial` 900:511 | 900 | 361 |
| 상세 Story | `editorial` 3:4 | 1345 | 361 |
| 상세 Texture | `detail-texture` 1345:641 | 1345 | 361 |

```css
.media { position: relative; width: 100%; aspect-ratio: var(--ratio); overflow: hidden; }
.media > img { width: 100%; height: 100%; object-fit: cover; }
/* 상품 카드 모델 컷아웃: 배경 위에 하단 기준으로 올림 */
.product-card__model { object-fit: contain; object-position: bottom center; }
```

### 2.4 전체 폭 크롭 이미지 (확정)
Hero와 Campaign은 모바일에서 비율을 유지한 채 **화면보다 넓게 배치하고 좌우를 잘라 낸다.**

| | PC | Mobile 이미지 | Mobile 가시 영역 |
|---|---|---|---|
| Hero | 1920×1080 (16:9) | 602×339 (x −133) | 393×339 |
| Campaign | 1920×770 | 520×209 (x −59) | 393×209 |

구현: 컨테이너 높이를 모바일 실측값 비율로 두고 `object-fit: cover; object-position: center`. 모바일 컨테이너 비율은 Hero 393:339, Campaign 393:209다. 다른 폭에서 이 높이를 고정값으로 둘지, 비율로 둘지는 §7.3 참조.

## 3. 상품 목록 (Product Grid)

### 3.1 PC (확정)
- 3열, 카드 587, 열 간격 20, 행 간격 135
- 디자인은 칸을 비워 두는 비대칭 배치다 ([components.md §4](components.md#4-product-grid)).

### 3.2 Mobile (요구사항: 2열)
모바일 Shop 프레임은 1열(361px)로 그려져 있지만, 요구사항에 따라 **2열로 구현한다.** 2열 값은 모바일 레이아웃 그리드와 Home 모바일 카테고리 카드(2열, 176/177px, gap 8)에서 가져온다.

| 속성 | 값 | 근거 |
|---|---|---|
| 열 수 | 2 | 요구사항 |
| 열 간격 | 8 | 모바일 그리드 gutter, Home 카테고리 2열 실측 |
| 카드 폭 | `(100% − 8px) / 2` → 393 기준 176.5 | 계산 |
| 이미지 비율 | 3:4 → 393 기준 176.5 × 235.3 | `aspectRatio.product` (Home TOPS 카드 176×235와 일치) |
| 이미지 → 메타 | 6 | 모바일 Frame 5 실측 |
| 행 간격 | **미확정** | 1열 디자인 값 29 또는 Home 2열 카테고리 행 간격 19 중 선택 필요 → §7.2 |
| 메타 레이아웃 | **미확정** | 디자인 메타(Frame 5)는 360 폭 가로 배치(이름 275 + 스와치/아이콘). 176 폭에는 들어가지 않는다 → §7.2 |

```css
.product-grid {
  display: grid;
  grid-template-columns: repeat(2, minmax(0, 1fr));   /* mobile */
  column-gap: var(--layout-product-grid-column-gap);   /* 8px */
}
@media (min-width: /* 전환 지점 미확정 */) {
  .product-grid { grid-template-columns: repeat(3, minmax(0, 1fr)); column-gap: 20px; row-gap: 135px; }
}
```

> 모바일 1열/2열 보기 토글 아이콘이 디자인에 있다. 2열을 기본으로 하고 1열(디자인 원본)을 토글 옵션으로 남길지는 §7.2에서 확인한다.

## 5. 반응형 구현 원칙
1. **값은 토큰의 `{desktop, mobile}` 쌍을 전환한다.** 중간 값을 보간(clamp/vw)할지는 §7.4 제안 사항이다.
2. **이미지는 항상 `aspect-ratio`로 높이를 계산한다** (§2.3).
3. **PC에서 좌우로 놓인 블록은 모바일에서 세로로 쌓는다**: Stockists, 상세 구매 패널, Q&A 행, Footer.
4. **모바일에서 빠지는 요소**: Footer Legal 링크·Contact 목록, Shop 타이프라이터, SeasonNav 시즌 텍스트, 상세 갤러리 Prev/Next 버튼. 이 요소들은 모바일에서 숨긴다. 대체 UI는 디자인에 없다.
5. **hover 의존 기능**(이미지 교체, 확대, Stockist 강조)은 PC 기준이다. 터치 대응은 §7.5.

## 6. 확인된 모바일 가독성 리스크 (보고만 함, 값은 변경하지 않음)
모바일 디자인에 8–10px 텍스트가 많다. 디자인 원본을 바꾸지 않는다는 원칙에 따라 그대로 기록했다.

| 요소 | 모바일 크기 |
|---|---|
| 구매안내 본문, 사이즈 표, 상품 설명 오버레이, 인덱스 숫자 | 8px |
| 캠페인 헤딩, 브랜드 문구, Footer, 상세 Info/탭, 상품 가격 | 10px |

iOS Safari는 16px 미만 입력 필드에 포커스하면 화면을 자동 확대한다. 이후 입력 폼(Q&A 작성 등)을 디자인할 때 고려가 필요하다.

## 7. 제안 항목 (디자인에 없음 · 확정 아님)

### 7.1 브레이크포인트 제안
| 이름 | 범위 | 레이아웃 | 근거 |
|---|---|---|---|
| `mobile` | 0 – 767 | Mobile 토큰 | 393 디자인 |
| `tablet` *(제안)* | 768 – 1279 | 디자인 없음. Mobile 레이아웃을 넓혀 쓰거나 PC 레이아웃 축소 중 선택 필요 | — |
| `desktop` | 1280 – | PC 토큰 | 1920 디자인 |
| `desktop-max` *(제안)* | 1920 – | 콘텐츠 최대폭 1800 고정, 바깥 여백 증가 | `layout/content-width` 변수 |

- 768 / 1280은 흔히 쓰는 값일 뿐, 디자인에서 나온 숫자가 아니다.
- 1280–1919 구간에서 PC 고정 수치(카드 587, 헤딩 80 등)를 그대로 쓰면 넘친다. 컨테이너 기준 비율로 축소하는 방식을 제안한다 (§7.4).

### 7.2 모바일 2열 상품 카드 세부값 (디자이너 확인 필요)
| 항목 | 선택지 |
|---|---|
| 행 간격 | A) 29 (모바일 1열 실측) · B) 19 (Home 모바일 2열 카테고리 실측) |
| 메타 배치 | A) 이름/가격 세로 + 아래 줄에 스와치·장바구니 · B) 이름/가격만 표시하고 스와치 숨김 |
| 상품명 크기 | A) 14 유지 (Frame 5) · B) 축소 (디자인 값 없음) |
| 1열 보기 | 토글로 유지할지 여부 |

### 7.3 Hero / Campaign 중간 폭 처리
모바일 가시 비율(393:339, 393:209)을 유지할지, PC 비율(16:9, 1920:770)로 넘어갈지 정해야 한다.

### 7.4 유동 타이포 (선택)
PC/M 두 값 사이를 `clamp()`로 보간하는 방식. 예: `font-size: clamp(20px, 4.17vw, 80px)` (섹션 헤딩, 80/1920 = 4.17vw). 디자인 값이 아니라 계산식이므로 적용 여부는 확인이 필요하다.

### 7.5 터치 기기 hover 대체
- 상품 카드 이미지 교체: 탭하면 상세로 이동, 교체 없음 (제안)
- Collections 확대 / Stockist 강조: 터치에서는 적용하지 않음 (제안)
- `@media (hover: hover)` 안에서만 hover 효과를 적용

### 7.6 PC Shop 비대칭 그리드
A) 디자인의 5행 패턴을 반복 · B) 일반 3열 그리드로 채움. 상품 수가 바뀌는 실제 목록에서 어떻게 할지 결정이 필요하다.
